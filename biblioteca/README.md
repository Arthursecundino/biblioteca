ORGANIZADOR DE BIBLIOTECA PESSOAL

Recebi a seguinte tarefa:

Você foi contratado para desenvolver um programa que ajude a organizar livros,
revistas, álbuns de música e outros itens pessoais. 
Esses itens devem ser agrupados por categorias, como suspense, romance, tecnologia, música,
entre outras que o próprio usuário pode escolher.

Criação de uma biblioteca de itens pessoais com progamação orientada a objeto em java, sem utilizar exceções, usando Listas para simular banco de dados.
Uma atividade de POO pura para pratica de desenvolvimento.
